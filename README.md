# MindAbs App

This is a minimal full-stack application built with **Node.js/Express** on the backend and **Next.js/SCSS Modules** on the frontend. The system ingests an Excel spreadsheet reporting situations, stores them in a local **SQLite** database, and surfaces them via documented APIs to the user interface.

## 📂 Project Structure

- `backend/` - Node.js + Express + TypeScript, SQLite, Zod
- `frontend/` - Next.js (App Router) + SCSS Modules, SWR, Zod

## 🚀 Setup & Run Instructions

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
The server will start on `http://localhost:3001` and create a `database.sqlite` file.
**Swagger API Docs:** `http://localhost:3001/api-docs`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
The Next.js client will start on `http://localhost:3000`. Navigate to this URL to view the UI.

## 🗄️ Database Choice + Schema
**Choice:** SQLite
**Why?** SQLite is chosen for minimal friction. It automatically creates the DB file locally without requiring a separate database server setup, which ensures reviewers can clone and run it seamlessly.

**Schema (situations row)**
```sql
CREATE TABLE situations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    scenario TEXT,
    age_group TEXT,
    cognitive_pillar TEXT,
    difficulty TEXT,
    question TEXT,
    options TEXT,
    expected_outcome TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
